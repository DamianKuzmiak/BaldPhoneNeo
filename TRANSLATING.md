# Translating BaldPhone Neo

Thank you for your interest in making BaldPhone Neo accessible to more people! We're building this with seniors in mind - it needs to be simple and intuitive. Your translations are absolutely key to making that happen.

If you encounter any problems, please [open an issue](https://github.com/DamianKuzmiak/BaldPhoneNeo/issues) or contact me at neo.baldphone@gmail.com.

## Translation Principles

- **Keep it Simple**: Use common, everyday words. Avoid technical jargon (e.g., use "Connect" instead of "Sync").
- **Be Clear and Concise**: Space is limited on big buttons. Try to keep translations short.
- **Respect the Context**: If possible, install the app to see where the strings appear. Some words have different meanings depending on their location.

## How to Contribute

### Option 1: For Non-Git Users (Email)

1. Open the [English `strings.xml`](https://github.com/DamianKuzmiak/BaldPhoneNeo/blob/master/app/src/main/res/values/strings.xml) file.
2. Click the "Raw" button to view the plain text and copy the text into a text editor, like Notepad.
3. Translate the text and save the file as `strings.xml`
4. Email it to neo.baldphone@gmail.com. Please include your name if you'd like to be credited!

### Option 2: For Git Users (Pull Request)

1.  **Fork** the repository.
2.  Create a new branch named `translation-xx` (replace `xx` with the [ISO 639-1 language code](https://en.wikipedia.org/wiki/List_of_ISO_639-1_codes)).
3.  Copy the `app/src/main/res/values` directory and rename it to `app/src/main/res/values-xx` (again, using the language code).
4.  In the new `values-xx` folder, translate the `strings.xml` file.
5.  Add your name and language to this `TRANSLATING.md` file.
6.  **Commit** your changes and open a **pull request**.

## Fixing an Existing Translation

1.  Navigate to the `strings.xml` file for the language you want to fix from the list above.
2.  Click the "edit this file" button (pencil icon).
3.  Make your corrections.
4.  Propose the changes.
